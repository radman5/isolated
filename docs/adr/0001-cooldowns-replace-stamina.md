# Cooldowns replace stamina

The combat prototype paid for every action from one stamina pool: dodges, sword swings, each chain link and the bow draw. We are removing stamina entirely. Taught skills (the charged chain now, and later AOE attacks and others) each get their own cooldown, which scales with how much you put in (more chain links mean a longer cooldown) and shrinks as the skill levels up with use. The dodge gets a short cooldown too, and a plain swing is free.

Why: a pool shared by every action makes skills compete with dodging, and it doesn't scale to a growing set of skills that each level up on their own. Per-skill cooldowns are easy to read and give each skill its own knob to level. The cost is that spamming basic actions is limited only by animation commitment and the dodge cooldown, not by a resource. Attrition (health never regenerates on its own) is unaffected.
